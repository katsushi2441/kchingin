# Kurage 最低賃金・賃上げ助成金チェック（kchingin）

従業員の時給の一覧から、新しい地域別最低賃金を下回る人数と、月・年の人件費の増加、業務改善助成金をまだ申請できるかと助成額の目安を計算する、1ファイルの PHP です。

公開: https://kurage.exbridge.jp/kchingin.php/

## できること

- 47都道府県の令和8年度の最低賃金（改定額・発効日）と、業務改善助成金の申請締切（発効日の前日と11月30日の早い方）を、今日の日付で表示
- 時給の一覧を貼ると、下回る人数・不足額・月と年の増加額
- 業務改善助成金の50・70・90円コースごとに、引上げ後の最低時給・人数に入る人・助成上限・助成額の目安・自己負担
- 都道府県ごとのページ（`/p/23/` など）、業務改善助成金のページ（`/josei/`）、`sitemap.xml`・`robots.txt`・`llms.txt`

時給の計算はブラウザの中だけで行い、入力した数字はサーバーへ送りません。

## しないこと

助成金の申請書の作成・申請の代行はしません。計算は目安で、要件と金額は労働局の審査で決まります。

## 置き方

`php/kchingin.php` を PHP 8.1 以上のサーバーに置くだけです（データベース不要）。`SITE` / `BASE` 定数を自分の URL に変えてください。

## データの更新

年度が変わったら、`MW`（都道府県ごとの改定額・改定前の額・発効日）と `JOSEI_*`（申請期間・助成率の境目・助成上限）を、厚生労働省の資料から差し替えます。

- 令和8年度 地域別最低賃金 答申状況: https://www.mhlw.go.jp/content/11302000/001745621.pdf
- 令和8年度業務改善助成金のご案内: https://www.mhlw.go.jp/content/11200000/001693381.pdf
